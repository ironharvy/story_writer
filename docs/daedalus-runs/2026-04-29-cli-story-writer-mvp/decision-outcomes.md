# Decision Outcomes

- CLI-only MVP was preserved.
- Local Ollama remains default; no paid provider route is active by default.
- DSPy stage graph was implemented as separate stage modules.
- Chapter beats are embedded in `chapter_plan`; no separate `chapter_beats` stage in MVP.
- QA is detection-first with R1-R8.
- Existing legacy run artifacts are render-tolerated, but not treated as proof of quality.
